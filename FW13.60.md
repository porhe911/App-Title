# PS5 13.00 / 13.60 support

App Title v0.2.17 supports the shared exact Hermes v89 HomeUI profile (`rnps-home 13.0.0+22834`) on 13.00 and 13.60. The private 13.00 fixture matches the 13.60 profile. Outside mode anchors the enclosing View rather than the nested Text; inside mode is unchanged. Unknown or altered profiles are refused.

## Run and configure

Download `App_Title_v0.2.17.elf` from [Releases](https://github.com/porhe911/App-Title/releases/tag/v0.2.17). New Media shortcut registration on firmware 12+ remains unavailable. Configure `/data/AppTitle/config.ini` over FTP before launch:

```ini
enabled=1
position=bottom
color=ffffff
placement=outside
```

`position` also accepts `top`; `placement` accepts `inside`. Fully reboot before replacing a resident payload. The settings server is loopback-only.
