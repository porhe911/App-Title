# PS5 13.60 support

App Title 0.2.15 includes the exact Hermes v89 HomeUI profile from PS5 13.600.007
(`rnps-home 13.0.0+22834`). The existing 11.60 profile remains supported.
Unknown or altered profiles are rejected before writing to the bundle.
Only numeric metadata and digests are included; no firmware bundle is shipped.

The 13.60 profile supports the existing top/bottom, inside/outside and color
settings. Inside placement preserves the native title background; outside
placement reserves space for the ID and native game title.

## Run and configure

Build `dist/App_Title_v0.2.15.elf` using the instructions in `BUILDING.md`, then
load it with a compatible privileged ELF loader after jailbreak.
Reboot before replacing a resident payload or retrying after ShellUI restarts.

New Media shortcut registration on firmware 12+ remains unavailable. Configure
`/data/AppTitle/config.ini` over FTP before launch:

```ini
enabled=1
position=bottom
color=ffffff
placement=outside
```

`position` also accepts `top`; `placement` also accepts `inside`. The existing
settings server remains bound to localhost.

The native bootstrap worker detaches from Mono after metadata/JIT preparation.

## Console verification

estate737 reports title IDs and styling verified on PS5 13.600.007 with the
stock HomeUI for PR #3, commit `613df61a39ecc8cf0f57df00ff63aad8646d2c6a`.
The released 0.2.15 ELF was confirmed by the owner on 4.03. A separate check
of this combined ELF on 13.60 is still pending. No 13.60 firmware
fixture was supplied for the integration run; generator checks do not replace it.
Other firmware revisions are not claimed to be supported.
