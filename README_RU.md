# App Title

Отдельная ELF-нагрузка для PS5: показывает ID игр и приложений на домашнем экране. Настройки открываются через постоянный ярлык **Мультимедиа → App Title**.

**App Title 0.2.15:** 24.10.2026 владелец подтвердил, что версия работает на 4.03. Объединены исправления живого RAM, освобождение ресурсов, короткие журналы, ручная диагностика и точный профиль 13.60 от estate737 из [PR №3](https://github.com/porhe911/App-Title/pull/3). Публикуется тот же ELF, который прошёл эту проверку. Для 13.60 подтверждение относится к сборке автора PR; отдельной проверки этого общего ELF на 13.60 пока нет.

## Пример

![App Title: белые ID игр и приложений под иконками на домашнем экране PS5](docs/images/app-title-preview.jpg)

ID отображаются под иконками, за пределами изображения. По умолчанию выбран белый цвет.

## Возможности

- ID вида CUSA00001 и PPSA03846 над изображением или под ним.
- Отдельное место для подписи за пределами изображения; доступен и вывод внутри иконки.
- Восемь цветов и свой цвет HEX из шести символов.
- По умолчанию — белые ID под изображением.
- Сохранение настроек в `/data/AppTitle/`.
- Самостоятельный ELF, etaHEN не требуется.
- Повторная активация через autoload после перезагрузки.

## Совместимость

| Прошивка | Формат HomeUI | Проверка |
| --- | --- | --- |
| 4.03 | `rnps-home_v2_ppr_releases_04.00`, Indexed RAM bundle | Владелец подтвердил работу 0.2.15 после предложенной проверки внешнего режима, положения и цвета — 24.10.2026 |
| 11.60 | `rnps-home 11.1.0+21887 / PS5 11.20 HOMEUI`, Hermes v89 | Рабочая база 0.2.8 подтверждена пользователем; генерация и применение Hermes-патча сохранены |
| 13.600.007 | `rnps-home 13.0.0+22834`, Hermes v89 | Проверка на консоли заявлена estate737 для PR №3; общий ELF ещё не проверен независимо |

Поддержка всех прошивок не заявляется. Для Hermes проверяется полный пакет; для RAM — загрузочный код, таблица и условия каждой правки, описанные в [BUILDING.md](BUILDING.md). При отказе проверки весь буфер остаётся без изменений. Регистрация нового Media-ярлыка на прошивках 12+ не реализована.

На 13.60 настройки нужно записать через FTP до запуска ELF: [FW13.60.md](FW13.60.md). Профиль отображения ID не добавляет регистрацию ярлыка на прошивках 12+.

Для запуска нужны рабочий jailbreak и совместимый ELF loader с привилегиями. Сам App Title не выполняет jailbreak.

## Установка

1. Скачай `App_Title_v0.2.15.elf` из [Releases](https://github.com/porhe911/App-Title/releases/tag/v0.2.15) либо собери его из этих исходников. В [опубликованной 0.2.8](https://github.com/porhe911/App-Title/releases/tag/v0.2.8) профили 4.03 и 13.60 отсутствуют.
2. Замени прежнюю версию в autoload или удали её запись.
3. Полностью перезагрузи PS5, чтобы удалить прежний резидентный компонент из памяти.
4. Выполни jailbreak и загрузи ELF один раз вручную либо через autoload.
5. Подожди 20–30 секунд и открой **Мультимедиа → App Title** на 4.03/11.60. Для 13.60 используй конфиг, описанный выше.

Выбери «Вне иконки» или «Внутри иконки», верх/низ и цвет. Нажми **«Сохранить»** либо **OPTIONS**. Меню обновится для применения настроек. Поддерживаются стрелки и ✕.

Ярлык остаётся после перезагрузки. Для отображения ID и открытия настроек нужен вновь запущенный ELF; это можно настроить через autoload. Несколько версий в одном сеансе не загружай. Если перезапустилась ShellUI, перед новым запуском App Title полностью перезагрузи консоль.

## Настройки и журналы

Файлы находятся в `/data/AppTitle/`. Пример автоматически сохраняемого config.ini:

```ini
enabled=1
position=bottom
color=ffffff
placement=outside
```

`position`: top/bottom; `placement`: outside/inside. Старый конфиг без placement поддерживается.

AppTitle.log ограничен 8 КиБ: результат последнего сохранения заменяет прежнюю строку. AppTitle_shellui.log обновляет короткий снимок результата при смене режима; постоянного текстового журнала нет.

Если внешний режим на 4.03 не применился, нажми «Подготовить файл для диагностики» и вернись в домашнее меню на 5 секунд. При включённых ID и работающем RAM-перехвате создаётся `/data/AppTitle/HomeUI_live.bin` — фактический RAM до наших правок. В остальных случаях остаётся прежний экспорт `/data/AppTitle/HomeUI_decrypted.bin`. Настройки показывают фактический путь. Дамп создаётся только по кнопке; его не следует публиковать в репозитории.
